Troubleshooting & FAQ

Common issues and solutions

Common Issues

Voice Input Not Working

Problem: Whisper not recognizing voice

Solutions:

# 1. Check microphone permissions (Windows)
Settings → Privacy → Microphone → Allow apps

# 2. Verify PyAudio installation
pip uninstall pyaudio
pip install pipwin
pipwin install pyaudio

# 3. Test microphone manually
python -c "import pyaudio; p = pyaudio.PyAudio(); print(p.get_default_input_device_info())"

# 4. Check Whisper model
import whisper
model = whisper.load_model("small")  # Should download if missing

ESP32 Connection Issues

Problem: Serial port not detected

Solutions:

# 1. Install CH340 or CP2102 driver (Windows)
# Download from manufacturer website

# 2. Check COM port
# Device Manager → Ports (COM & LPT)
# Note the COM number (e.g., COM3)

# 3. Update config.yaml
esp32:
  port: "COM3"  # Use your COM port

# 4. Test serial connection
python -m serial.tools.miniterm COM3 115200

# 5. Re-flash firmware if needed
cd esp32_firmware
pio run --target upload

Import Errors

Problem: ModuleNotFoundError

Solutions:

# 1. Verify virtual environment is activated
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 2. Reinstall dependencies
pip install -r requirements.txt --upgrade

# 3. Check Python version
python --version  # Should be 3.10 or higher

# 4. Install missing modules individually
pip install openai
pip install chromadb
pip install sentence-transformers

Out of Memory Errors

Problem: Whisper crashes with OOM

Solutions:

# 1. Use smaller Whisper model
# In config.yaml:
whisper:
  model: "tiny"  # Instead of "small" or "base"

# 2. Enable CPU-only mode
model = whisper.load_model("small", device="cpu")

# 3. Close other applications
# Free up RAM before running JARVIS

# 4. Increase virtual memory (Windows)
# Settings → System → About → Advanced system settings
# → Performance Settings → Advanced → Virtual memory

ChromaDB Issues

Problem: Vector store errors

Solutions:

# 1. Delete and recreate database
rm -rf data/chroma/
# Or on Windows:
rmdir /s data\chroma

# 2. Update ChromaDB
pip install chromadb --upgrade

# 3. Check storage path permissions
# Ensure write access to ./data/ directory

# 4. Use SQLite backend explicitly
import chromadb
client = chromadb.PersistentClient(
    path="./data/chroma",
    settings=chromadb.Settings(anonymized_telemetry=False)
)

OpenAI API Errors

Problem: Authentication failed

Solutions:

# 1. Check API key format
# Should start with "sk-"
# Get from: https://platform.openai.com/api-keys

# 2. Update config.yaml
openai:
  api_key: "sk-your-actual-key-here"

# 3. Set environment variable (alternative)
export OPENAI_API_KEY="sk-your-key"

# 4. Check billing
# Ensure account has credits: https://platform.openai.com/account/billing

# 5. Rate limiting
# Wait 60 seconds if hitting rate limits

Frequently Asked Questions

Can I use this without OpenAI API?

Yes! You can use local LLMs like LLaMA or Mistral instead of GPT-4. The system will be slower but fully offline.

Do I need a GPU?

Recommended for Whisper STT (4GB+ VRAM). You can use CPU-only mode but expect 5-10x slower transcription.

Can I run this on Linux/Mac?

Yes! Most code is cross-platform. PowerShell tools won't work, but you can use bash equivalents.

How much does it cost to run?

Hardware: ~$25-110. API costs: $10-30/month for GPT-4 (depending on usage). Can be $0 with local LLMs.

Is my data private?

Local mode: Yes, everything stays on your PC. Cloud mode: Voice/text sent to OpenAI API (check their privacy policy).

Can I add custom tools?

Absolutely! See the Code Library section for examples. JARVIS is designed to be extensible.

What languages are supported?

Whisper supports 90+ languages. LLM reasoning works best in English but can handle multiple languages.

How do I update JARVIS?

Pull latest code, update dependencies (pip install -r requirements.txt --upgrade), and re-flash ESP32 firmware if needed.

Still Having Issues?

If you've tried everything and still can't resolve the problem:

  • Check logs in logs/jarvis.log
  • Run with verbose mode: python app/main.py --verbose
  • Review error stack traces carefully
  • Search GitHub issues for similar problems
  • Ask the community for help
