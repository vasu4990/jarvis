Software Setup

Complete Python environment and dependency installation

Installation Guide

Step 1: Install Python 3.10+

# Windows 11
# Download from python.org
# Make sure to check "Add Python to PATH"

# Verify installation
python --version
# Should output: Python 3.10.x or higher

Step 2: Create Project Directory

# Create project folder
mkdir jarvis-ai
cd jarvis-ai

# Create virtual environment
python -m venv venv

# Activate virtual environment
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

Step 3: Install Dependencies

# Create requirements.txt
pip install openai>=1.0.0
pip install whisper
pip install chromadb
pip install sentence-transformers
pip install playwright
pip install pyautogui
pip install pyserial
pip install pyyaml
pip install fastapi
pip install uvicorn
pip install sqlalchemy

# Or use requirements file
pip install -r requirements.txt

Step 4: Download ML Models

# Download Whisper model
import whisper
model = whisper.load_model("small")

# Download sentence transformers
from sentence_transformers import SentenceTransformer
embedder = SentenceTransformer('all-MiniLM-L6-v2')

# Models will be cached automatically

Step 5: Configuration

# Create config.yaml
cat > config.yaml << EOF
openai:
  api_key: "your-openai-api-key-here"
  model: "gpt-4"

whisper:
  model: "small"
  language: "en"

esp32:
  port: "COM3"  # Windows
  # port: "/dev/ttyUSB0"  # Linux
  baud_rate: 115200

memory:
  chroma_path: "./data/chroma"
  sqlite_path: "./data/jarvis.db"

safety:
  permission_level: "yellow"  # green, yellow, red
  require_confirmation: true
  audit_logging: true
EOF

Step 6: Run JARVIS

# Launch JARVIS
python app/main.py

# System tray icon should appear
# Press Ctrl+Space to speak
# Say: "Hello JARVIS"

# Emergency kill: Ctrl+Shift+K
