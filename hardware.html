Wiring Diagram

ESP32 DevKit (30-pin) Connections:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WS2812B LED Ring:
  DIN  → GPIO 25 (ESP32)
  VCC  → 5V (ESP32)
  GND  → GND (ESP32)

Wake Button:
  Pin 1 → GPIO 4 (ESP32)
  Pin 2 → GND (ESP32)
  (with 10kΩ pull-up to 3.3V)

Kill Switch:
  Pin 1 → GPIO 5 (ESP32)
  Pin 2 → GND (ESP32)
  (with 10kΩ pull-up to 3.3V)

USB Serial:
  Connect ESP32 to PC via Micro-USB

Pin Summary:

│ GPIO 5      │ Kill Switch  │
│ 5V          │ LED Power    │

└─────────────┴──────────────┘

Build Steps

1

Place ESP32 on Breadboard

Insert ESP32 DevKit into breadboard, ensuring pins are aligned on both sides.

2

Wire WS2812B LED Ring

DIN → GPIO 25, VCC → 5V, GND → GND

Use 5V for LED power, not 3.3V

3

Connect Wake Button

Button pin 1 → GPIO 4, pin 2 → GND. Add 10kΩ resistor from GPIO 4 to 3.3V (pull-up).

4

Connect Kill Switch

Button pin 1 → GPIO 5, pin 2 → GND. Add 10kΩ resistor from GPIO 5 to 3.3V (pull-up).

5

Flash Firmware

Connect USB cable. Install PlatformIO and flash firmware (see Software section).

6

Test Hardware

Press wake button → LED should turn blue. Press kill switch → LED should turn red.

Firmware Installation

Step 1: Install PlatformIO

# Install PlatformIO CLI
pip install platformio

# Or use VS Code extension
# Install "PlatformIO IDE" extension

Step 2: Prepare Firmware

# Download firmware from Code Library section
# Or clone repository:
git clone https://github.com/your-repo/jarvis-esp32-firmware

cd jarvis-esp32-firmware

Step 3: Configure

# Edit platformio.ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino

# Edit src/config.h
#define LED_PIN 25
#define WAKE_BUTTON_PIN 4
#define KILL_SWITCH_PIN 5

Step 4: Flash

# Connect ESP32 via USB
# Build and upload
pio run --target upload

# Monitor serial output
pio device monitor --baud 115200
